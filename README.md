# Product Sales Analysis

**Project:** Client Sales Report

**Tools Used:** MySQL, SQL, Microsoft Excel

## Project Objective
Analyze completed sales orders and calculate total sales for each product.

## Work Completed
- Filtered orders with `Completed` status.
- Calculated total sales using `SUM(Amount)`.
- Grouped sales by product using `GROUP BY`.
- Sorted products by total sales in descending order.

## Results

| Product | Total Sales |
|---|---:|
| AC | 5,500 |
| Fridge | 2,000 |

**Total Completed Sales: 7,500**

## Files Delivered
- `product_sales_query.sql` — SQL analysis query
- `product_sales_report.csv` — Final sales report
- `README.txt` — Project explanation

## Conclusion
AC generated the highest sales, contributing approximately 73.3% of the total completed sales in this dataset.
